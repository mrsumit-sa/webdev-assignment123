# P2: Portfolio Repository with Initial Commit

## Objective
To learn how to initialize a Git repository, track files
and create the first commit.

## Commands Used

### 1. pwd
Displays the current working directory.

### 2. cd folder_path
Navigates to the specified directory.

### 3. git init
Initializes a new Git repository in the current directory.

### 4. touch README.md
Creates an empty README Markdown file.

### 5. echo "text" > README.md
Writes text into README.md.
The > operator creates or overwrites the file.

### 6. echo "text" >> README.md
Appends text to the existing file without deleting
its previous contents.

### 7. cat README.md
Displays the contents of README.md in the terminal.

### 8. git status
Displays the current state of the working directory
and staging area.

### 9. git add README.md
Adds README.md to the staging area so it can be committed.

### 10. git commit -m "Initial commit"
Creates the first commit with the message
"Initial commit".

### 11. git log --oneline
Displays the commit history in a short format.

## Tasks Completed
- Initialized a Git repository.
- Created a README file.
- Added the file to the staging area.
- Created the initial commit.
- Verified the commit history.

## Learning Outcome
Learned Git initialization, file tracking, staging
and committing changes.

## Tools Used
- macOS Terminal
- Git
