# PROGRAMMING FOR WEB DEVELOPMENT - I LABORATORY

## Module 1: Terminal, Git & GitHub

## P1: Project Folder and Terminal Navigation

### Aim
To create a project folder and learn basic terminal navigation commands.

### Requirements
- Terminal
- macOS or Linux operating system

### Commands Used

| Command | Purpose |
|---------|---------|
| pwd | Displays current working directory |
| ls | Lists files and folders |
| mkdir | Creates a new folder |
| cd | Moves into a folder |
| cd .. | Moves one level back |
| touch | Creates a new file |
| clear | Clears the terminal screen |

### Procedure

1. Open the Terminal.
2. Check the current location using pwd.
3. Display files using ls.
4. Create a project folder:

   mkdir web-development

5. Enter the folder:

   cd web-development

6. Create a text file:

   touch P1.txt

7. Verify the file:

   ls

8. Check the current directory:

   pwd

### Expected Output

P1.txt

The current directory path should end with:

/web-development

### Result

Successfully created a project folder named web-development and learned basic terminal navigation commands.
