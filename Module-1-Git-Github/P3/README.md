# P3: Feature Branch Git Workflow

## Objective
To understand Git branching, switching between branches
and merging changes into the main branch.

## Commands Used

### 1. git init
Initializes a new Git repository.

### 2. git branch
Displays the available branches in the repository.

### 3. git branch feature-about
Creates a new branch named feature-about.

### 4. git switch feature-about
Switches to the feature-about branch.

### 5. git switch main
Switches back to the main branch.

### 6. echo "text" >> README.md
Appends new content to README.md.

### 7. git add README.md
Adds the modified README file to the staging area.

### 8. git commit -m "message"
Saves the staged changes as a new commit.

### 9. git merge feature-about
Merges the changes from feature-about into
the currently active branch.

### 10. git log --oneline --graph --all
Displays the commit history of all branches
in a graphical format.

### 11. cat README.md
Displays the contents of README.md.

## Tasks Completed
- Initialized a Git repository.
- Created an initial commit.
- Created a feature branch.
- Switched between branches.
- Added and committed changes.
- Merged the feature branch into main.

## Learning Outcome
Learned how Git branches allow developers to work
on separate features and combine their changes.
