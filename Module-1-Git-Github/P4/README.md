# P4: README and Version Tags

## Objective
To understand project documentation, Git commits
and version tagging.

## Commands Used

### 1. git init
Initializes a new Git repository.

### 2. echo "text" > README.md
Creates or overwrites README.md with the given text.

### 3. echo "text" >> README.md
Appends additional text to README.md.

### 4. git add README.md
Adds the README file to the staging area.

### 5. git commit -m "message"
Creates a commit with the specified message.

### 6. git tag -a v1.0 -m "Version 1.0"
Creates an annotated Git tag named v1.0.
The tag identifies a particular project version.

### 7. git tag -a v1.1 -m "Version 1.1"
Creates another annotated tag named v1.1.

### 8. git tag
Displays all tags in the repository.

### 9. git log --oneline --decorate
Displays the commit history and associated tags
in a short format.

## Tasks Completed
- Initialized a Git repository.
- Created project documentation.
- Created commits for project changes.
- Created version tags v1.0 and v1.1.
- Verified the tags and commit history.

## Learning Outcome
Learned how to document projects and use Git tags
to identify different project versions.
